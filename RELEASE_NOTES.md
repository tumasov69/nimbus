# Nimbus — release notes

## v0.5.3

**Сеть больше не зависает навсегда**
- У всех сетевых запросов появились таймауты. Раньше при молчаливом обрыве связи каталог, проверка обновлений или загрузка игровых файлов могли «висеть» бесконечно. Медленные, но живые загрузки при этом не прерываются.
- Исправлено ложное сообщение об ошибке сети, если установка обновления занимала больше 30 секунд (например, из-за проверки антивирусом).

**Сохранность данных**
- Если файл сборок или аккаунтов окажется повреждён, он больше не затирается пустым — сохраняется копия с расширением `.corrupt`, данные можно восстановить.
- Удаление мира теперь запрашивает подтверждение: мир удаляется безвозвратно, мимо корзины.

**Прочее**
- Главная проверяет обновления сборок аккуратнее — меньше нагрузки на диск и процессор при открытии.
- Статус в Discord восстанавливается после перезапуска Discord (раньше требовался перезапуск лаунчера).

## v0.5.2

**Автообновление**
- Исправлено зависание загрузки обновления навсегда при обрыве соединения (у загрузки не было таймаута). Теперь при 30 секундах без данных загрузка прерывается с понятным сообщением и можно повторить.
- Таймаут проверки обновлений — лаунчер больше не ждёт бесконечно недоступный сервер.

**Обновление модов**
- При обновлении мода автоматически доустанавливаются новые обязательные зависимости, которых требует свежая версия.
- «Обновить все» работает в несколько параллельных загрузок и честно сообщает, сколько модов обновилось, а сколько — с ошибкой.
- Включение/выключение мода стало мгновенным (без пересканирования всех файлов и запросов к Modrinth).

## v0.5.1

**Производительность игры**
- Оптимизированные JVM-флаги по умолчанию (набор G1 GC + предвыделение памяти), когда поле Java-аргументов пустое — меньше фризов при генерации чанков и пауз сборщика мусора. Свои аргументы, как и раньше, имеют приоритет.
- Логи игры передаются в интерфейс пачками, а не по строке — меньше фоновой нагрузки лаунчера во время игры.

**Безопасность**
- Ссылки из описаний модов открываются только в системном браузере.
- Иконки категорий каталога проходят строгую фильтрацию содержимого.
- Файлы модпаков (.mrpack) скачиваются только с доверенных доменов (Modrinth, GitHub, GitLab) — по спецификации Modrinth.
- Настройки, сборки и аккаунты записываются атомарно — сбой или выключение ПК во время записи больше не может испортить данные.
- Усилена проверка путей во внутренних командах лаунчера.

**Интерфейс и исправления**
- Список сборок плавнее во время установки (убраны лишние перерисовки карточек).
- Починена автопрокрутка логов при появлении новых строк.
- Проверка обновлений модпаков кэшируется — главная открывается быстрее и меньше нагружает Modrinth API.
- Ошибки при смене/удалении аккаунта теперь показываются уведомлением.

## v0.5.0

**Командная палитра (Ctrl+K)**
- Быстрый переход к любой странице, сборке или переключение аккаунта с клавиатуры (работает при любой раскладке). Кнопка поиска вверху бокового меню.

**Аккаунты**
- Быстрое переключение активного аккаунта прямо из бокового меню (выпадающий список с головами).

**Серверы (вкладка сборки)**
- Пинг серверов: онлайн/слоты, задержка и иконка сервера.
- Кнопка ▶ — мгновенный вход на сервер при запуске игры.

**Учёт времени игры**
- Накопленное время в игре по каждой сборке — на странице сборки и на карточках.

**Главная — «Обновления»**
- Список сборок с доступными обновлениями модпака и модов одним блоком.

**Логи**
- Поиск по логам, фильтр по уровню (всё/предупреждения/ошибки), подсветка ошибок и совпадений, умная автопрокрутка.

**Каталог**
- Вкладка «Дата-паки» с категориями.

**Уведомления**
- Системные уведомления о завершении долгих операций (установка модпака, обновление модов), когда лаунчер свёрнут. Переключатель в настройках.

**Прочее**
- Оптимизация, чистка неиспользуемого кода и зависимостей, исправления (в т.ч. корректный разбор IPv6-адресов серверов).

## v0.4.0

**Авто-перевод каталога**
- Описания модов и модпаков переводятся на язык интерфейса (заголовки/названия остаются оригинальными). Тумблер перевода в каталоге и кнопка «Перевести описание» на странице проекта.
- Без дневных лимитов и без ошибок-заглушек в тексте.

**Скины — полноценный выбор**
- Новое окно смены скина: галерея готовых скинов (превью в 3D), применение скина **любого игрока по нику**, загрузка своего PNG.
- Превью результата до применения, выбор модели (классическая/тонкая), авто-определение модели у выбранного игрока.
- Окно крупнее и аккуратнее — элементы больше не съезжают.

**Главная — живее**
- Блок «Популярные модпаки» с обложками прямо на главной — сразу видно, что поставить, в один клик к установке.

**Окно**
- Лаунчер открывается **по центру монитора** в комфортном крупном размере.

**Дизайн «Nimbus Sky»**
- Карточки сборок в стиле обложек: баннер из иконки, большая кнопка Play при наведении, парящая иконка; карточки крупнее и читаемее.
- Главная: градиентный hero «небо» с фирменными облаками и светящейся кнопкой запуска.
- Страницы мода и сборки: шапка с размытым баннером — как в магазинах игр.
- Переработанная **тёмная тема**: глубже и чище фон, заметно приподнятые карточки, более яркий акцент.
- Чистые кнопки без лишних градиентов, аккуратные тени, увеличенные радиусы.
- Все темы: светлая, тёмная, OLED, прозрачность Mica.

**Исправления и надёжность**
- Меню «…» на карточке сборки больше не обрезается (рендерится поверх через портал).
- Кнопки в шапках не слипаются на узком окне.
- Точная диагностика при поиске скина по нику (не «игрок не найден» при сбое сервиса Mojang).
- Защита от удаления сборки во время установки; устранены утечки таймеров и гонки при обновлении списков.

## v0.3.3

**Самостоятельный аудит — исправления найденных недоработок**

- Запуск второй копии лаунчера больше не возможен (раньше две копии могли испортить данные сборок) — вторая просто фокусирует первую.
- Смена скина теперь работает всегда: токен Microsoft автоматически обновляется перед загрузкой (раньше через сутки после входа выдавало ошибку 401).
- Для ванильных сборок вкладка контента теперь показывает ресурспаки — раньше она смотрела в папку модов, а установки шли в ресурспаки (несостыковка).
- «Проверить файлы» работает без добавленного аккаунта.
- Лаунчер запоминает размер и положение окна.
- При недоступности Modrinth в каталоге появляется кнопка «Повторить» вместо пустого экрана.

## v0.3.1

**Оптимизация и стабильность** (по итогам полного аудита тремя проверками)

- Лаунчер больше не перерисовывает весь интерфейс на каждой строке лога игры (логи теперь обновляются пакетами) — заметно меньше нагрузка на CPU во время игры.
- Список модов открывается мгновенно при повторном заходе: метаданные Modrinth кэшируются, jar-файлы не перехешируются без необходимости.
- Хеширование модов стало потоковым — не загружает большие файлы в память целиком.
- Кэш поиска в каталоге: больше, с умным устареванием (10 минут) — навигация по вкладкам без повторных запросов.
- Бейдж «Установлено» появляется сразу после установки мода.
- Экспорт сборки пишется через временный файл — обрыв не оставит битый .mrpack.
- Плавнее индикаторы загрузки, убраны утечки памяти на логах удалённых сборок.

## v0.2.0

**Крупное обновление — управление сборками как у больших лаунчеров**

**Сборки**
- Обновление модпаков Modrinth до новой версии одной кнопкой (старые файлы убираются, ваши моды остаются).
- Экспорт сборки в `.mrpack` — поделиться с друзьями.

**Моды**
- Клик по моду открывает его страницу.
- Вкладка «Зависимости» на странице мода.

**Удобство**
- Мастер первого запуска: язык, ник и сразу в игру.
