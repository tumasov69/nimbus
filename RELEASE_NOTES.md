# Nimbus — release notes

## v0.4.0

**Авто-перевод каталога**
- Описания модов и модпаков переводятся на язык интерфейса (заголовки/названия остаются оригинальными). Тумблер перевода в каталоге и кнопка «Перевести описание» на странице проекта.
- Без дневных лимитов и без ошибок-заглушек в тексте.

**Скины — полноценный выбор**
- Новое окно смены скина: галерея готовых скинов (превью в 3D), применение скина **любого игрока по нику**, загрузка своего PNG.
- Превью результата до применения, выбор модели (классическая/тонкая), авто-определение модели у выбранного игрока.
- Окно крупнее и аккуратнее — элементы больше не съезжают.

**Главная — живее**
- Блок «Популярные модпаки» с обложками прямо на главной — сразу видно, что поставить, в один клик к установке.

**Окно**
- Лаунчер открывается **по центру монитора** в комфортном крупном размере.

**Дизайн «Nimbus Sky»**
- Карточки сборок в стиле обложек: баннер из иконки, большая кнопка Play при наведении, парящая иконка; карточки крупнее и читаемее.
- Главная: градиентный hero «небо» с фирменными облаками и светящейся кнопкой запуска.
- Страницы мода и сборки: шапка с размытым баннером — как в магазинах игр.
- Переработанная **тёмная тема**: глубже и чище фон, заметно приподнятые карточки, более яркий акцент.
- Чистые кнопки без лишних градиентов, аккуратные тени, увеличенные радиусы.
- Все темы: светлая, тёмная, OLED, прозрачность Mica.

**Исправления и надёжность**
- Меню «…» на карточке сборки больше не обрезается (рендерится поверх через портал).
- Кнопки в шапках не слипаются на узком окне.
- Точная диагностика при поиске скина по нику (не «игрок не найден» при сбое сервиса Mojang).
- Защита от удаления сборки во время установки; устранены утечки таймеров и гонки при обновлении списков.

## v0.3.4

**Запуск лаунчера**
- Убрано дёргание окна при старте (окно меняло размер на глазах) — теперь лаунчер появляется сразу готовым, в правильном размере и месте.
- Запуск ощущается быстрее: исчез белый «пустой» кадр перед загрузкой интерфейса.

**Исправления**
- Настройки выровнены как остальные вкладки (были по центру).
- Смена иконки сборки теперь видна сразу (раньше показывалась старая из кэша).
- Мастер первого запуска больше не появляется повторно, если его пропустили.

**Дизайн**
- Активный пункт меню отмечен акцентной полоской (стиль Windows 11).
- Карточки заметнее подсвечиваются при наведении.

## v0.3.3

**Самостоятельный аудит — исправления найденных недоработок**

- Запуск второй копии лаунчера больше не возможен (раньше две копии могли испортить данные сборок) — вторая просто фокусирует первую.
- Смена скина теперь работает всегда: токен Microsoft автоматически обновляется перед загрузкой (раньше через сутки после входа выдавало ошибку 401).
- Для ванильных сборок вкладка контента теперь показывает ресурспаки — раньше она смотрела в папку модов, а установки шли в ресурспаки (несостыковка).
- «Проверить файлы» работает без добавленного аккаунта.
- Лаунчер запоминает размер и положение окна.
- При недоступности Modrinth в каталоге появляется кнопка «Повторить» вместо пустого экрана.

## v0.3.2

**Скорость**
- Страница мода открывается мгновенно: описание показывается сразу, список версий (у популярных модов это мегабайты данных) грузится фоном.
- Страницы модов и списки версий кэшируются на 10 минут — повторное открытие без ожидания.
- Зависимости мода запрашиваются только при открытии вкладки.
- Иконки модов декодируются асинхронно — список не подвисает при прокрутке.

**Описания модов**
- Теперь корректно отображаются спойлеры (`<details>/<summary>`), выравнивание, встроенные изображения и видео — как на сайте Modrinth (с безопасной фильтрацией HTML).

**Галерея**
- Клик по скриншоту открывает его в полном размере (лайтбокс), превью аккуратнее, с плавным зумом при наведении.

**Скины**
- Предпросмотр выбранного файла скина до загрузки (рядом с текущим).
- Ссылка на каталог скинов NameMC.

**Интерфейс**
- Починена поехавшая вёрстка раздела «Внешний вид» в настройках.

## v0.3.1

**Оптимизация и стабильность** (по итогам полного аудита тремя проверками)

- Лаунчер больше не перерисовывает весь интерфейс на каждой строке лога игры (логи теперь обновляются пакетами) — заметно меньше нагрузка на CPU во время игры.
- Список модов открывается мгновенно при повторном заходе: метаданные Modrinth кэшируются, jar-файлы не перехешируются без необходимости.
- Хеширование модов стало потоковым — не загружает большие файлы в память целиком.
- Кэш поиска в каталоге: больше, с умным устареванием (10 минут) — навигация по вкладкам без повторных запросов.
- Бейдж «Установлено» появляется сразу после установки мода.
- Экспорт сборки пишется через временный файл — обрыв не оставит битый .mrpack.
- Плавнее индикаторы загрузки, убраны утечки памяти на логах удалённых сборок.

## v0.3.0

**Аккаунты и скины**
- Смена скина Minecraft прямо в лаунчере для лицензионных аккаунтов Microsoft (классическая/тонкая модель).

**Сборки**
- Папки для группировки сборок (как в Prism) — назначай папку через меню сборки, фильтруй чипами.
- В каталоге уже установленные моды и модпаки помечаются «Установлено».

**Каталог Modrinth**
- Все категории Modrinth, сгруппированные по разделам, с заметным выделением выбранных.

**Интерфейс**
- Настоящий логотип Nimbus в боковой панели.
- В настройках памяти можно вписать число вручную, ползунок плавнее.
- Настройки лучше подстраиваются под размер окна.

**Обновления**
- Принудительное обновление при запуске — лаунчер ставит новую версию сразу, не дав работать на устаревшей.
- При выпуске на GitHub остаётся только актуальная версия.

**Качество**
- Исправлены непереведённые строки, общая оптимизация и чистка.

## v0.2.0

**Крупное обновление — управление сборками как у больших лаунчеров**

**Сборки**
- Обновление модпаков Modrinth до новой версии одной кнопкой (старые файлы убираются, ваши моды остаются).
- Экспорт сборки в `.mrpack` — поделиться с друзьями.
- Импорт `.mrpack` перетаскиванием в окно.
- Клонирование сборки (полная копия с модами и мирами).
- Свои иконки для сборок.
- Вкладка «Миры»: список, бэкап в zip, удаление, открыть папку.
- Вкладка «Серверы»: добавление/удаление серверов (пишется в servers.dat игры).
- Проверка и починка файлов игры.

**Моды**
- Клик по моду открывает его страницу.
- Вкладка «Зависимости» на странице мода.

**Удобство**
- Мастер первого запуска: язык, ник и сразу в игру.
- Уведомление, если игра вылетела, с кодом ошибки.
- Скелетоны при загрузке каталога, кэш результатов поиска.

**Безопасность и надёжность**
- Токены Microsoft теперь шифруются на диске (Windows DPAPI).
- Повторные попытки при обрыве загрузки.
- Настройка числа параллельных загрузок.

**Прочее**
- Статус «играет в Minecraft» в Discord (можно отключить).
